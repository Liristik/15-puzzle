15-Puzzle (Пятнашки) на C++

Классическая игра-головоломка «Пятнашки», написанная на языке C++ с использованием графической библиотеки graphics.h (WinBGI). Задача игрока — перемещать плитки по полю, чтобы упорядочить их по номерам



Особенности проекта:

Игровая матрица 4×4: Динамическое перемещение плиток на игровом поле с помощью кликов мыши.  

Рандомизация: Автоматическое случайное заполнение поля цифрами от 1 до 15 при старте игры. 

Графический вывод: Отрисовка тайлов и победного экрана (win.JPG) с использованием растровых изображений (loadBMP).

Проверка победы: Отслеживание правильного порядка плиток на поле для завершения игры


Технологии:

Язык программирования: C++  Библиотека графики: graphics.h / WinBGI

Алгоритмы: Двумерные массивы, функции перемещения элементов (std::swap), обработка событий ввода.


Как запустить:

Убедитесь, что настроена среда разработки с поддержкой graphics.h (WinBGI).

Поместите файл с кодом и все графические файлы с цифрами в одну папку.

Запустите проект в вашей IDE.
